# Sanket Das — Frontend Engineer & Creative Developer

Welcome to the source code for my interactive developer portfolio. This project is a dual-mode web experience designed to showcase both my creative coding abilities and my rigorous software engineering standards.

## 🌟 Dual-Mode Architecture

This portfolio features a unique toggle system that allows visitors to switch between two distinct perspectives at any time:

- **Creative Mode**: An immersive, WebGL-powered 3D experience built with React Three Fiber. It focuses on fluid animations, procedural geometry, and emotional resonance.
- **Engineering Mode**: A clean, accessible, performance-driven view. It strips away the canvas to reveal technical architecture, problem-solving methodologies, and system metrics.

## 🛠️ Tech Stack

- **Framework**: React 18 & Vite
- **Styling**: Tailwind CSS
- **3D Graphics**: Three.js & React Three Fiber (@react-three/fiber, @react-three/drei)
- **Animation**: Framer Motion & GSAP (GreenSock)
- **Scrolling**: Lenis (Smooth Scroll)
- **Routing**: React Router

## 🚀 Getting Started

To run this project locally:

1. **Install dependencies**:
   ```bash
   npm install
   ```

2. **Start the development server**:
   ```bash
   npm run dev
   ```

3. **Build for production**:
   ```bash
   npm run build
   ```

## 🎨 Design Philosophy

- **Performance as a Constraint**: Optimizing shaders and reducing React re-renders is treated as a creative challenge, not just an engineering metric.
- **Micro-Interactions**: Every hover state, cursor movement, and transition is carefully choreographed to feel alive and responsive.
- **Graceful Degradation**: The site is fully responsive, scaling gracefully from large desktop monitors down to mobile devices without losing its core identity.
